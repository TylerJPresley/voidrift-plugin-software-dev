# @voidrift/plugin-software-dev

VoidRift Software Development — development skills, agents and tools on top of the generic core.

Part of VoidRift, a local-first, model-agnostic AI agent harness. Status: skeleton (0.1.0), not yet usable or released. The VoidRift CLI and core are the current focus.

## Requirements
- Node.js >=24
- `@voidrift/core` `^0.1.0`, which is not published to npm yet. Until it is, link a local checkout of the core repository (`npm link @voidrift/core`).

## Build from source
```bash
git clone https://github.com/TylerJPresley/voidrift-plugin-software-dev.git
cd voidrift-plugin-software-dev
npm install
npm run build
npm test
```
